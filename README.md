# 🛒Ecommerce App

**Ecommerce App** es una aplicacion de comercio electronico, ** construida con una arquitectura de microsrvicios **

## 🚀 Tecnologias utilizadas

La aplicacion utiliza un conjunto de tecnologias modernas para garatizar la escalabilidad, seguridad y eficiencia de la misma.

- **Lenguaje:** Java 21
- **Framework:** Spring boot 3 (Spring Web MVC, Spring Data JPA, Spring Security, Spring Cloud).
- **Base de datos:** MySQL 8, PostgreSQL y MongoDB.
- **Mensajeria y Cache:** Redis y Apache Kafka.
- **Seguridad:** Json Web Token (JWT)
- **Testing:** Postman y cURL
- **Documentacion:** Swagger
- **Gestion de dependencias:** Maven
- **Herramientas y desarrollo:** Kubernetes, Docker, Linux, IntelliJ IDEA.

## 🔨 Arquitectura

La aplicacion sigue un enfoque basado en **microservicios**, lo que permite la escalabilidad y mantenimiento modular. Cada servicio se comunica mediante **REST API** y utiliza Apache Kafka para la mensajeria asincrona.
